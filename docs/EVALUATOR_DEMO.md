# Evaluator Demo Guide

## Roles
- Admin: account approval, global dashboards, audit and exports.
- Regional Officer: cases in the assigned Region; scrutiny/EVC/committee processing actions.
- Institution Head: applications and compliance records for the registered institution.

## Demo sequence
1. Admin signs in and opens Users to inspect/approve registration requests.
2. Institution Head creates an application, selects an APH-style pathway and uploads supporting files using drag-and-drop.
3. Regional Officer opens the application, reviews details, completes a stage or returns it with a mandatory reason.
4. Regional Officer schedules an EVC from the EVC queue.
5. Demonstrate undertaking and lease/document due dates, renewal states and verification actions.
6. Admin reviews alerts, region-wise pendency, CSV export and audit chain.
7. Advance the demo workflow date to show reminders and escalation levels.

## Safety note
All displayed seed data and the date simulator are illustrative. No automated action constitutes statutory approval or replaces an authorised official.
